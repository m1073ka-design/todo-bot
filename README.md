# Todo Bot

Telegram bot orqali vazifalarni qo'shish, ko'rish va boshqarish mumkin.

## Imkoniyatlar

- Vazifa qo'shish
- Vazifalarimni ko'rish
- Vazifani bajarilgan deb belgilash
- Vazifani o'chirish
- Statistika
- Vazifalar SQLite bazasida saqlanadi

## Ishga tushirish

```bash
pip install -r requirements.txt
python bot.py
